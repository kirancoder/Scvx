# Scvx
This implementation is MATLAB version of https://github.com/EmbersArc/SCvx/tree/master with only the 2D and 3D rocket landing problems with fixed final time conditions.
The folder FixedFinalTime contains the 2D and 3D rocket landing files with solved using SDPT3 solver which is doesn't need license. 
The folder FreeFinalTime, which will be adoption of the same Github repo, but will free final conditions will be implemented i.e. sigma will be design variable, initial guess is taken from the load_parameters.m file

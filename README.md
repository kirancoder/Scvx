# Scvx
This implementation is MATLAB version of https://github.com/EmbersArc/SCvx/tree/master with only the 2D and 3D rocket landing problems with fixed final time conditions.
The folder FixedFinalTime contains the 2D and 3D rocket landing files with solved using SDPT3 solver whihc is doesn't need license. 
The new folder FreeFinalTime will be added which will be adoption of the same Github repo, but will free final conditions will be implemented.

# Scvx
This implementation is MATLAB version of https://github.com/EmbersArc/SCvx/tree/master with only the 2D and 3D rocket landing problems.
The folder FixedFinalTime contains the 2D and 3D rocket landing files with solved using SDPT3 solver which is doesn't need license. 
The folder FreeFinalTime, which will adopt the same Github repo, but will free final conditions, will be implemented, i.e., sigma will be the design variable, initial guess will be taken from the load_parameters.m file
